# WMS 后端新增模块模板（通用）

> 基于 `wms` 项目现有代码规范与 PostgreSQL 语法，新增任意业务模块时按此模板创建文件。
>
> **占位符说明：**
> - `{模块名}` — Java 包名模块段，如 `warehouse`、`rcs`、`system`
> - `{Xxx}` — 类名前缀（PascalCase），如 `WmsLocation`、`RcsTask`
> - `{xxx}` — 表名/URL 路径（小写），如 `wms_location`、`rcs_task`
> - `{日期}` — 创建日期，如 `2026-07-23`

## 一、目录结构


## 十五、关键规则速查

| 规则 | 说明 |
|---|---|
| 实体类 | 继承 `BaseEntity`，主键用 `id`（BIGSERIAL），时间字段覆盖父类映射 `created_time`/`updated_time` |
| 状态字段 | 用 `SMALLINT`（PostgreSQL 不支持 TINYINT），0=禁用 1=启用 |
| 查询参数 | 继承 `BaseQuery`（含 pageNum、pageSize） |
| DTO | 使用 `@Schema` + `@NotBlank`/`@NotNull` 校验注解 |
| VO | 使用 `@Schema` + `@JsonFormat` 格式化时间 |
| Mapper | 继承 `BaseMapper<T>`，加 `@Mapper` 注解 |
| XML | namespace 全限定名匹配 Mapper 接口，OGNL 表达式引用 QueryDTO 属性 |
| Service | 继承 `IService<T>`，实现类继承 `ServiceImpl<Mapper, Entity>` |
| 事务 | `@Transactional(rollbackFor = Exception.class)` 加在 impl 方法上 |
| Controller | `@PreAuthorize("@ss.hasPerm('{模块名}:{xxx}:动作')")` 权限控制 |
| 转换器 | MapStruct `@Mapper(componentModel = "spring")`，放在 `utils/` 目录 |
