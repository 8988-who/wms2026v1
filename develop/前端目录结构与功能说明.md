# WMS 前端目录结构与功能说明

## 一、技术栈概览

| 技术 | 说明 |
|------|------|
| Vue 3 | 渐进式 JavaScript 框架（Composition API） |
| TypeScript | 类型安全 |
| Vite | 构建工具 |
| Pinia | 状态管理 |
| Vue Router | 路由管理 |
| Element Plus | UI 组件库 |
| UnoCSS | 原子化 CSS |
| VXE Table | 高性能表格 |
| ECharts | 图表可视化 |
| WangEditor | 富文本编辑器 |
| Knife4j | API 文档对接 |

## 四、架构特点

1. **Composition API**: 全量使用 Vue 3 Composition API + `<script setup>` 语法
2. **TypeScript**: 全量 TypeScript，类型安全
3. **CURD 封装**: `PageSearch + PageContent + PageModal + usePage` 通用 CRUD 封装，新增页面只需配置列和表单
4. **权限控制**: 路由级权限守卫 + `v-permission` 按钮级权限指令
5. **状态管理**: Pinia 模块化 Store（user/permission/dict/settings/tags-view/app/tenant）
6. **SSE 实时推送**: 字典变更同步 + 在线用户数广播
7. **多布局模式**: 左侧/顶部/混合/双栏四种布局可切换
8. **国际化**: i18n 中英双语支持
9. **主题切换**: 亮/暗主题 + Element Plus CSS 变量覆盖
10. **请求封装**: Axios 统一拦截（Token 注入/错误处理/响应解构）
