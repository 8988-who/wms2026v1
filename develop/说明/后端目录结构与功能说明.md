# WMS 后端目录结构与功能说明

## 一、顶层包概览

根包：`com.wms`，包含以下 10 个核心模块包：

| 包名 | 功能说明 |
|------|---------|
| `auth` | 认证授权模块（登录、验证码、令牌刷新、短信登录） |
| `business` | 业务模块（API 请求日志记录，对接外部系统的接口调用追溯） |
| `carriermanagementsystem` | 载具管理系统模块（料车、料车型号配置、料车物品管理/装车取走） |
| `common` | 公共基础模块（注解、基类、常量、枚举、异常、结果、工具、校验） |
| `file` | 文件存储模块（本地存储、阿里云 OSS、MinIO） |
| `framework` | 框架基础设施（API 文档、缓存、验证码、邮件、短信、XXL-Job、MyBatis、安全、Web） |
| `message` | 消息推送模块（SSE 实时推送字典变更、在线用户广播） |
| `rcs` | RCS 管理系统模块（AGV 调度对接 + RCS 本地任务全生命周期管理） |
| `system` | 系统管理模块（用户、角色、菜单、部门、字典、配置、日志、第三方绑定） |
| `warehouse` | 仓库管理模块（库位/区域、巷道、点位） |

> 说明：`RcsTaskServiceImpl` 内置统一状态流转方法 `changeStatus(...)`，在同一事务内更新主表状态/时间戳并写入一条 `wms_rcs_task_lifecycle` 历史。**下发闭环（阶段三）**：新增任务后立即调用 RCS `AGV_submitTask` 接口，远程调用在数据库事务外进行，成功后经代理触发 `REQUIRES_NEW` 事务回填 `rcs_task_id` 并流转为"已派发"，失败则流转为"异常"（可通过 `/{id}/submit` 重试）；`reqCode` 使用本地任务编号保证 RCS 侧幂等。**取消联动（阶段四）**：`/{id}/cancel` 对"待执行"任务（尚未下发）本地直接流转"已取消"，无需远程调用；对"已派发/执行中"任务先在事务外调用 RCS `AGV_cancelTask`，成功后经代理触发 `REQUIRES_NEW` 事务流转"已取消"，失败则抛 `BusinessException` 明确反馈且不改变任务状态；已完成/已取消/异常等终态任务拒绝取消。

## 六、架构特点

1. **分层清晰**: Controller → Service(Impl) → Mapper（严格三层架构）
2. **RESTful 规范**: `/api/v1/{resource}` 路径 + 语义化 HTTP 方法
3. **统一响应**: `Result<T>` / `PageResult<T>` 封装
4. **细粒度权限**: `@PreAuthorize("@ss.hasPerm('xxx')")` + Spring Security
5. **数据权限**: Role.dataScope + SysRoleDept + MyBatis 拦截器（五级粒度：全部/部门及子部门/本部门/本人/自定义）
6. **操作日志**: `@Log` 注解 + AOP 切面异步记录
7. **安全机制**: JWT/Redis 双 Token 管理器、图形/短信验证码、接口限流、防重复提交
8. **仓库结构**: "库位/区域 → 巷道 → 点位" 三级层级，支持级联停用、自动编码生成（Redis INCR）
9. **缓存策略**: 菜单权限 Read-Through 缓存、字典变更 SSE 实时推送、系统配置启动时加载
10. **消息推送**: SSE 实时推送字典变更和在线用户数广播
11. **载具管理**: "料车型号 → 料车 → 料车物品" 三级结构，双保险状态更新（SQL 子查询实时计算 + Service 手动维护），支持扫码装车/取走（条码机/PDA 对接）
12. **外部系统对接**: `ApiEnum` 枚举统一管理 RCS 接口配置（AGV 6 个接口），`ApiRequestUtils` 统一请求入口（POST/GET/WebService），自动记录请求日志到 `api_request_log`（含耗时/重试次数/链路追踪ID），按模块解析返回值（预留 if-else 扩展点）
13. **RCS 本地任务管理**: 在"纯转发"之上新增本地任务台账（`wms_rcs_task` + `wms_rcs_task_lifecycle`），任务 6 态生命周期（待执行→已派发→执行中→已完成/已取消/异常），统一状态流转入口 `changeStatus` 同事务写状态变更历史，可追溯、可对账；`payload` 用 JacksonTypeHandler 映射 PostgreSQL jsonb 扩展参数
14. **RCS 联动闭环（远程调用与事务解耦）**: 下发（`AGV_submitTask`）与取消（`AGV_cancelTask`）均将 HTTP 远程调用置于数据库事务外，避免长事务占用连接；调用结果经自注入代理（`@Lazy self`）触发 `REQUIRES_NEW` 独立事务落库，规避 Spring 自调用导致 `@Transactional` 失效。下发失败置"异常"态可重试；取消失败抛 `BusinessException` 明确反馈且不改变状态；`reqCode` 复用本地任务编号保证 RCS 侧幂等
15. **RCS 回调反向链路（入站驱动状态流转）**: `RcsReporterController`（`/api/v1/rcs/reporter/**`）承接 RCS 主动回馈（任务执行/任务告警/机器人告警），按 `taskCode` 优先、`rcsTaskId` 兜底反查本地任务，兼容字符串 `method` 与数值 `status` 两种来源映射本地 6 态，经 `changeStatus`（`operatorType=EXTERNAL`）驱动流转并落 lifecycle；回调暂不鉴权（需放行 + 预留独立 token/IP 白名单 TODO），未匹配任务仅记录日志并返回成功码避免重试风暴
